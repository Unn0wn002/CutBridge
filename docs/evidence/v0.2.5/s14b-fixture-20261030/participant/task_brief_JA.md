# タスク指示書 — S14B-FX01

このカットを、次の内容で CutBridge に設定してください（JP03）。操作方法は書いていません。画面から探してください。

## 使うファイル

- Blender ファイル: `S14B_FX01_start.blend`
- スタジオプリセット: `studio_preset_s14b_fx01.json`

## カット情報

| 項目 | 値 |
| --- | --- |
| Project | `S14B` |
| Episode | `EP01` |
| Scene | `SC001` |
| Cut | `C001` |
| Take | `T01` |
| Version | `1`（最初のパッケージ） |

## 出力設定

| 項目 | 値 |
| --- | --- |
| カメラ | `CAM_MAIN` をアクティブカメラにする |
| FPS | 24 |
| 解像度 | 960 × 540（100%） |
| フレーム範囲 | 1 〜 12 |
| 出力先 | モデレーターが用意した空のフォルダー |
| プリセット | カスタム（Custom）で `studio_preset_s14b_fx01.json` を使う |

開いた直後のファイルは、上の値と**一致していません**。すべて確認して合わせてください。

## パス

- `BEAUTY`（必須）と `LINE`（任意）の 2 つです。プリセットに含まれています。

## アーティスト作業（JP07 で追加）

After Effects でコンポジションを組み立てた後、次の「自分の作業」を追加してください。

1. 新しいレイヤー（平面やヌルなど）を 1 つ追加する
2. どれかのレイヤーにエフェクトを 1 つ追加する
3. どれかのレイヤーにマスクを 1 つ描く
4. どれかのレイヤーの不透明度を変える
5. 2 つのレイヤーを親子関係にする

この作業が、後の V002・V003 への更新（JP09・JP10）でも残っているかを確認していただきます。
