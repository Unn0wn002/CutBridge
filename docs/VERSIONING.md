# Versioning

CutBridge uses semantic versioning during development.

- PATCH (`0.1.0` → `0.1.1`): compatible fixes.
- MINOR (`0.1.0` → `0.2.0`): new backward-compatible capabilities.
- MAJOR (`0.x` → `1.0.0` and later): production contract or compatibility changes that require deliberate migration.

The Blender extension version, release tag, changelog entry, and packaged artifact names should agree for every release.
