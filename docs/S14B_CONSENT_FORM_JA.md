このテストは**会ったり、通話やビデオ会議をしたりせずに**行います。

1. 同意のご返信をいただいた後、テスト用のファイル一式（CutBridge の ZIP 2 つ、テスト用素材、参加者ガイド、記録シート）をお送りします。
2. ご都合のよい時間に、ご自身のパソコンで参加者ガイドのタスクを進めてください。所要時間の目安は **90〜120 分**です。途中で休憩しても、数回に分けても構いません。

4. 終わったら、記録シートをお送りください。録画を選んだ方は、録画ファイルも一緒にお送りください（録画を選んだ後でも、送らないことにして構いません）。

## 3. ご自身のパソコンへの影響について

- **未リリースの開発版です。** 製品として公開・保証されたものではありません。
- Blender にアドオンを 1 つ、After Effects にスクリプトファイルを 4 つ追加します。
- **テスト用素材だけを使ってください。** ご自身の業務データや社外秘のファイルは開かないでください。念のため、大切なファイルのバックアップをおすすめします。
- **CutBridge は自動でデータを送信しません。** インターネットに接続するのは、Blender 側の「アップデートを確認」ボタンを押した場合だけです。その場合は GitHub Pages（github.io）から公開ファイルを取得します。一般的な Web サイトと同様に IP アドレスが相手に伝わりますが、テストのデータは送信されません。今回のテストでは押す必要はありません。なお、CutBridge のプリファレンスに「Check on Startup」（起動時に確認）の項目が表示されますが、このビルドでは機能を無効にしてあり、動作しません。
- **テスト後の削除方法:**
  - Blender: 「編集 → プリファレンス → アドオン」で CutBridge を探し、メニュー（▾）から「アンインストール」を選びます。
  - After Effects: 4 つのファイル（`CutBridge.jsx`、`revision_manager.js`、`qc_plus.js`、`localization.js`）を削除します。`Scripts/ScriptUI Panels` フォルダーにコピーした場合は、そこから削除してください。表示言語の設定が After Effects の環境設定に 1 件残りますが、無害です。
  - テスト中に作成したパッケージや AE プロジェクトのフォルダーも削除して構いません。
  - 手順は参加者ガイドにも記載します。
