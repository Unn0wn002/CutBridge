# CutBridge 利用テスト 参加者ガイド（v0.2.5 開発版・非同期版）

このガイドは、CutBridge の日本語ユーザーテスト（S14B）に参加していただく方向けです。テストは**ご自身のパソコンで、ご自身のペースで**進めていただきます。会ったり、通話したりすることはありません。

参加前に [説明・同意書](S14B_CONSENT_FORM_JA.md) をお読みいただき、同意のご返信をいただいている前提で書いています。

## はじめに

- テストするのは **CutBridge** で、**あなた**を評価するものではありません。迷ったり失敗したりした箇所こそ、改善に役立つ大切な情報です。
- 操作方法のサポートはありません。各タスクでは「目標」だけをお伝えします。やり方はご自身で探してください。
- 進められないタスクがあっても大丈夫です。記録シートに「どこで、なぜ止まったか」を書いて、次のタスクへ進んでください。
- 所要時間の目安は約 90〜120 分です。途中で休憩しても、数回に分けても構いません。
- **テスト用の素材だけを使ってください。** ご自身の業務データは開かないでください。

### 録画を選んだ方

- タスク JP01 を始める前に、画面録画を開始してください。休憩のときは止めて構いません。ファイルが複数になっても大丈夫です。
- **画面全体**を録画してください。作業中に Blender、After Effects、フォルダーなどを行き来するためです。
  - Windows: Snipping Tool の画面録画（「録画」を選び、画面全体を範囲に指定）、または OBS Studio など。Xbox Game Bar は 1 つのアプリしか録画できないため、使わないでください。
  - macOS: `Shift + Command + 5` で「画面全体を収録」を選びます。音声ありの方は「オプション」でマイクを選んでください。
- 「画面と音声」を選んだ方は、考えていることを声に出しながら進めてください（「このボタンは何だろう」「ここで保存されると思った」など）。
- 録画にお名前、メール、通知、他のウィンドウなどが映らないようにしてください。
- 記録シートには、各タスクを始めたときの録画の時刻を書いていただけると助かります（任意）。

### 0. ファイルの確認（ハッシュ値）

届いた 2 つの ZIP が正しいものかを確認します。

まず、届いたアーカイブ（`S14B-FX02-data-20261031.zip`）を任意のフォルダーに展開してください。中にある 2 つの ZIP（CutBridge 本体）は、まだ展開しないでください。次に、そのフォルダーでコマンドを実行します。

- Windows: 展開したフォルダーをエクスプローラーで開き、アドレスバーに `powershell` と入力して Enter を押すと、そのフォルダーで PowerShell が開きます。
- macOS: ターミナルを開き、`cd ` と入力（最後に半角スペース）してから、展開したフォルダーをターミナルのウィンドウにドラッグし、Enter を押します。

実行するコマンド:

- Windows（PowerShell）:

  ```text
  Get-FileHash -Algorithm SHA256 CutBridge-Blender-v0.2.5.zip, CutBridge-AfterEffects-v0.2.5.zip
  ```

- macOS（ターミナル）:

  ```text
  shasum -a 256 CutBridge-Blender-v0.2.5.zip CutBridge-AfterEffects-v0.2.5.zip
  ```

表示された値が次と一致するかを確認し、結果を記録シートに書いてください（大文字・小文字の違いは問題ありません）。

- `CutBridge-Blender-v0.2.5.zip`: `abf5882d56856d4662e95b2ac1335fb0dc6e818f5f7113235dce0529385b2207`
- `CutBridge-AfterEffects-v0.2.5.zip`: `ecfb26ce8e5ad50638e17b35104efc2210d222b4ac8f10fccf0fba2748c17d8f`

**一致しない場合は、ここでテストを止めて** 【連絡先】 までお知らせください。

## タスク

各タスクが終わるたびに、記録シートに「結果」「どうしたか」「迷ったこと・感じたこと」を書いてください。わからない用語や、意味を取り違えそうな表示があれば、それも書いてください。

### JP01 — Blender に CutBridge を入れる

`CutBridge-Blender-v0.2.5.zip` から CutBridge をインストールして有効にし、CutBridge のパネルを開いてください。

### JP02 — 画面の意味を確かめる

CutBridge のパネルを見て、次のものが何のためにあるかを、ご自身の言葉で記録シートに書いてください。

- Project / Episode / Scene / Cut / Take / Version の各項目
- カットを検証するボタンと、パッケージを作成するボタン
- Studio Preset のモード
- 表示される安全に関するメッセージやステータス

### JP03 — カットを設定する

`S14B_FX01_start.blend` を開き、タスク指示書のとおりに、メタデータ、アクティブカメラ、FPS、解像度、フレーム範囲、出力先、プリセットを設定してください。設定が終わったら、**別の名前でこのファイルを保存**してください（JP05 で使います）。

### JP04 — エラーから回復する

`S14B_FX01_JP04.blend` を開いてください。このファイルには、わざと問題を 1 つ入れてあります。カットを検証し、表示されたメッセージから何が問題かを読み取り、直して、もう一度検証を通してください。終わったら、このファイルは保存せずに閉じて構いません。

### JP05 — パッケージを作成する

JP03 で保存したファイルを開き、検証が通った状態でパッケージを作成してください。その後、指示書のフレーム範囲（1〜12）をすべてアニメーションとしてレンダリングしてください（レンダリングするまでパッケージは完成しません）。どのフォルダーに何ができたか、そのパッケージのバージョンは何か、同じバージョンでもう一度作成するとどうなると思うかを、記録シートに書いてください。

### JP06 — After Effects でパッケージを開く

`CutBridge-AfterEffects-v0.2.5.zip` から CutBridge パネルを使えるようにし、JP05 で作成したパッケージ（`cutbridge.json`）を読み込んでください。

ご自身のパッケージがどうしても読み込めない場合だけ、`fallback` フォルダーのパッケージを使って続けてください。**使った場合は、必ず記録シートに書いてください。**

### JP07 — After Effects 側を組み立てる

読み込んだパッケージからコンポジションを組み立ててください。その後、タスク指示書の「アーティスト作業」を追加し、CutBridge が管理しているものと、あなたが追加したものの違いを記録シートに書いてください。このプロジェクトを保存してください。

### JP08 — QC+ の結果を読む

1. JP07 のプロジェクトで QC+ を実行し、結果を記録シートに書いてください。
2. 次に、After Effects で**新しいプロジェクト**を作り、`JP08_qc_check` フォルダーのパッケージを読み込んで組み立て、QC+ を実行してください。このパッケージには、わざと問題を 1 つ入れてあります。何が問題で、どう対処すべきかを記録シートに書いてください。
3. 新しいプロジェクトは保存せずに閉じ、JP07 で保存したプロジェクトに戻ってください。

### JP09 — V002 に更新する

JP07 のプロジェクトを、`revisions` フォルダーの V002 のパッケージで更新してください。表示される確認メッセージの意味と、更新後のバージョンを記録シートに書いてください。

ご自身の V001 から更新できない場合は、表示された内容を記録シートの JP09 に書いてください。そのうえで、After Effects で**新しいプロジェクト**を作り、`fallback` の V001 を使って JP06（読み込み）と JP07（組み立て・アーティスト作業・保存）をもう一度行ってから、JP09 を続けてください（JP08 はやり直さなくて構いません）。**`fallback` を使ったことを、必ず記録シートの JP09 に書いてください。**

### JP10 — V003 に更新し、作業が残っているか確かめる

続けて、`revisions` フォルダーの V003 に更新してください。更新後、バージョンが V003 になったこと、そしてあなたのアーティスト作業（エフェクト、マスク、不透明度、手動で追加したレイヤー、親子関係）が残っているかを確認し、記録シートに書いてください。

### JP11 — 保存して開き直す

プロジェクトを保存し、After Effects を完全に終了してから起動し直してください。プロジェクトを開き、CutBridge パネルを開き直してください。パッケージの状態（バージョンなど）を確認し、QC+ をもう一度実行して、結果を記録シートに書いてください。

JP12（カメラ／3D ヌルの受け渡し）は、v0.2.5 では通常の画面操作から使えない機能のため、今回は実施しません。

## 終わったら

1. 録画を止めてください。録画を選んだ方は、送る前に、映ってはいけないものが映っていないか確認してください。録画を選んだ後でも、送らないことにして構いません。
2. 記録シート（と録画ファイル）を、【返送方法】 でお送りください。スクリーンショットの添付に同意した方は、添付したファイル名と、どのタスクの画面かを記録シートの「その他」に書いてください。
3. **CutBridge の削除**
   - Blender: 「編集 → プリファレンス → アドオン」で CutBridge を探し、メニュー（▾）から「アンインストール」を選びます。
   - After Effects: 4 つのファイル（`CutBridge.jsx`、`revision_manager.js`、`qc_plus.js`、`localization.js`）を削除します。`Scripts/ScriptUI Panels` フォルダーにコピーした場合は、そこから削除してください。表示言語の設定が After Effects の環境設定に 1 件残りますが、無害です。
   - テスト中に作成したパッケージ、AE プロジェクト、届いたファイル一式も削除して構いません。
